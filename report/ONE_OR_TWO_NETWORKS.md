# 抓握预测：用一个网络还是两个？

> 你的方案：**检测离手最近的物体 → 输出 4 种抓握状态**，抓握标签人工标注。
> 问题：**用一个神经网络还是两个？**
>
> **推荐：两个（解耦），而且"感知"那部分尽量用现成的。**

---

## 一、直接结论

```
┌─ 网络 1：感知（用现成的，不必自己训）────────────────┐
│  · 手   : MediaPipe HandLandmarker (7.5 MB)          │
│           → 21 个 2D 关键点 + 掌心位置 + 手框         │
│  · 物体 : YOLO(COCO) → 框（类别错无所谓，我们要中心） │
│  · 规则 : 选「框中心离掌心最近」的那个 = 目标物体      │
│           → 输出：物体框 + 框中心 + 掌心法向           │
└──────────────────────────────────────────────────────┘
                    ↓（裁剪出"手 + 物体"区域）
┌─ 网络 2：抓握分类（自己训，小模型）─────────────────┐
│  输入 = 裁剪图像（256×256）                          │
│  骨干 = MobileNetV3-Small (2.5M) / ViT-Tiny (5.8M)   │
│  输出 = 4 类 softmax                                 │
│        [五指抓握 | 三指抓握 | 两指勾 | ?]             │
└──────────────────────────────────────────────────────┘
```

---

## 二、⭐ 为什么推荐"两个"而不是"一个"

| # | 理由 | 说明 |
|---|------|------|
| **1** | **数据效率** ⭐ | 抓握标签要**人工标**，样本少。让分类器只吃"裁剪后的物体区域"（输入空间聚焦）比吃整图**少得多的样本**就能学好 |
| **2** | **可调试 / 可归因** | 检测错了能一眼看出来，不会和分类错误混在一起 |
| **3** | **可复用** | 检测器是现成的（COCO YOLO 我们实测框位置就对），**不用重新训** |
| **4** | **可替换** | 以后换检测器/换分类骨干，互不影响 |
| **5** | **论文能分开报告** ⭐ | "检测准确率"和"抓握分类准确率"是**两张独立的表**，审稿人爱看 |

### 什么时候才该用**一个**网络

| 条件 | 说明 |
|------|------|
| 标注量 **≥ 1 万级** | 多任务学习通常带来 5–15% 提升，但需要 3–5 倍数据 |
| **极致延迟要求** | 只能跑一次前向（如 30+ FPS 且算力极受限）|
| 两个任务**强相关**且共享像素级特征 | 例如都是分割 |

**→ 你是人工标注、样本有限 → 不满足条件 → 用两个。**

## 三、⚠️ 两个关键设计点（很容易踩坑）

### 坑 1：不要把手部姿态作为分类器输入（标签泄漏）

```
❌ 错误做法：
   输入 = 图像 + 当前手部 21 关键点
   标签 = 由"人实际用的抓握"标注
   → 模型会直接"看着手型猜手型"，推理时（手还没摆好）就废了

✅ 正确做法：
   输入 = 物体区域的图像（+ 可选：手的位置/朝向作为"当前状态"）
   不输入手部的【抓握姿态】本身
   → 手部信息只在【感知阶段】用来选最近物体、算掌心法向
```

### 坑 2：⭐ 训练/测试集要**按物体划分**（object-held-out）

```
❌ 随机划分：同一个物体既在训练集又在测试集
   → 模型会"记住这个物体 → 这个抓握"，而不是学"该用哪种抓握"
   → 测试准确率虚高（可能 95%+），换个新物体就崩

✅ 按物体划分：训练集物体 ∩ 测试集物体 = ∅
   → 真正检验"泛化到没见过的物体"
   → 这才是你论文该报的数字
```

**这是你毕设里最能体现工作量、也最能说服审稿人的一点。**

## 四、训练流程（5 步）

```
【1】采集
    4 类姿态 × 每个物体 × N 次（建议每类每物体 ≥ 20 次）
    ⭐ 最好记录：物体名、姿态名、可选的掌心法向

【2】自动裁剪 + 人工标类别
    用感知网络给出的框裁剪出"手+物体"区域（256×256）
    人工标 4 类之一   ← 你说的这一步

【3】划分
    ⭐ 按【物体】划分 train / val / test（object-held-out）
    也可再加"按被试划分"（subject-held-out）

【4】训练（两阶段，数据少时这么做）
    阶段 A：冻结骨干，只训线性头（几十~几百张就够，快速验证可行性）
    阶段 B：解冻最后 1–2 个 block 微调（提升精度）
    损失：CrossEntropy（可加类别权重处理不平衡）
    增强：随机裁剪 / 翻转（注意：翻转要谨慎，左右手有别）/ 亮度

【5】评测
    · 混淆矩阵（4×4）—— 看哪两类容易混
    · 按物体分组的准确率
    · 与"类别查表"baseline 对比  ← 论文的消融
```

## 五、需要你确认的一件事：**第 4 类是什么？**

你之前说的是 3 类：
| # | 姿态 | 分类学 | 用途 |
|---|------|--------|------|
| 1 | **五指抓握** | Power grasp | 圆柱/球/瓶罐 |
| 2 | **三指抓握** | Tripod / Precision | 小物体、精细 |
| 3 | **两指勾** | **Hook grasp** | 提袋子/手提物 |

**第 4 类我猜是**：
| 候选 | 说明 |
|------|------|
| **侧捏（lateral pinch）** | 拇指-食指**侧面**夹持：卡片、薄片、钥匙 |
| 或 **两指捏（pinch）** | 指尖对捏：小颗粒、硬币 |
| 或 **平台抓（platform）** | 手掌托举：盘子、书本 |

**请确认第 4 类是什么**，这决定采集清单。

## 六、一句话回答你

> **用两个网络。**
> - **网络 1（感知）**：手用 MediaPipe、物体用 YOLO，"离手最近"用**规则** —— **都不用自己训**
> - **网络 2（抓握分类）**：训一个 2.5–6 M 的小骨干，输入**裁剪后的物体区域**，输出 4 类
>
> **为什么两个**：人工标注样本少 → 解耦能大幅降低分类器的数据需求；而且可调试、可复用、论文里能分开报告指标。
>
> **两个必须避开的坑**：① 别把手部姿态喂进分类器（标签泄漏）；② **训练/测试按物体划分**（object-held-out），否则准确率虚高。
