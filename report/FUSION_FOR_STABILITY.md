# 视觉融合如何提升 EMG 控制的稳定性

> 问题：抓住物体**运动过程中**，EMG 受**肌肉运动伪影**、**疲劳**等影响 → 分布失衡 → 控制不稳
> 目标：用视觉输入让 EMG 控制**更稳**（而不是单纯更高精度）

---

## 一、⭐ 先拆问题：两种不稳定性本质不同

| | **短期扰动** | **长期漂移** |
|--|-------------|-------------|
| 来源 | 肌肉运动伪影、电极-皮肤位移、肢体运动引起的基线变化 | 疲劳、汗液、电极阻抗变化 |
| 时间尺度 | **毫秒–秒**（瞬时） | **分钟–小时**（缓慢） |
| 表现 | 信号**瞬时错误**（尖峰/畸变/幅值突跳） | 特征**分布整体平移**（P(fresh) ≠ P(fatigued)）|
| 正确应对 | **检测 + 拒绝/保持**（不能平均！）| **在线自适应**（不能拒绝！）|
| 用视觉怎么帮 | 视觉确认"当前状态没变"→ **冻结命令** | 视觉提供**在线伪标签**→ 重新校准解码器 |

> ⚠️ **关键认知**：对伪影做"加权平均"是错的——平均会把错误的瞬时值拉进输出。
> 伪影要**拒绝或冻结**；疲劳要**适应**。**两种病，两种药。**

---

## 二、五种融合机制（按能力递进）

### 机制 1：**状态门控**（State gating）—— 解决"何时信任 EMG"

视觉给出离散状态：`s ∈ {未接触, 接触-静止, 接触-运动中, 松开中}`
不同状态下用不同的解码策略：

```python
s = vision_state(frame)          # 视觉状态机
if s == "接触-运动中":            # 运动伪影高发期
    cmd = hold_last_command()    # 冻结，不更新（避免抖动）
elif s == "接触-静止":            # 稳定抓握
    cmd = emg_decoder(features)  # 正常解码
else:
    cmd = idle
```

**效果**：直接消除运动过程中的**命令抖动**（假肢手来回切换的问题）。
**代价**：几乎无（只需视觉状态）；**风险**：状态误判会导致错误冻结 → 需要滞回。

---

### 机制 2：**视觉先验兜底**（Vision prior）—— 让输出"不会乱跳"

抓握方式**大部分由物体决定**。把视觉作为**先验**，EMG 只做修正：

```
P(抓握 | EMG, 视觉) ∝ P(EMG | 抓握) · P(抓握 | 视觉)     ← 贝叶斯
                     = softmax(logit_EMG + logit_vis)   ← 对数域相加
```

**为什么能稳**：
- 当 EMG 被伪影污染（logit 乱）时，**视觉先验仍把输出钉在正确的抓握上** → 输出不会跳到无关类别
- 当视觉失效（遮挡），先验变成均匀分布 → 自动退回 EMG 主导

**实现**：`logit_final = logit_EMG + λ · logit_vis`，λ 由可靠性决定（见机制 3）。

---

### 机制 3：**可靠性自适应加权**（Reliability-aware fusion）⭐ 核心

分别估计两个模态的**在线可靠性**，动态调权：

| 模态 | 可靠性信号 |
|------|-----------|
| **EMG** | ① 伪影指数：>150–200 Hz 高频能量突增、幅值突跳、与视觉运动相关的大幅低频波动<br>② 模型不确定性：预测熵 / MC-dropout 方差 / 集成方差 |
| **视觉** | ① 检测置信度（shape/contact 的 softmax）<br>② 遮挡/出画标志<br>③ 帧质量（模糊、暗光）|

```python
r_emg = artifact_index(emg_window) * model_confidence(emg_logits)
r_vis = detection_confidence(vis_logits) * (1 - occlusion_flag)
w_emg, w_vis = softmax([r_emg / T, r_vis / T])      # T 为温度

logit_final = w_emg * logit_emg + w_vis * logit_vis
```

**效果**：EMG 变差 → 权重自动挪向视觉；视觉失效 → 挪回 EMG。
**这是最能直接回答你问题的一条**：伪影/疲劳期 EMG 可靠性下降 → 视觉顶上。

---

### 机制 4：**视觉锚定的在线自适应**（对抗疲劳）⭐ 最有新意

疲劳导致**缓慢漂移**，加权不够（加权是"平均"，不是"修正"）。需要**适应**：

```
视觉自信时（如：稳稳抓住球、接触=1、形状置信度高）
   → 视觉状态 = 高质量伪标签 y_hat
   → 用它做 test-time adaptation，更新 EMG 解码器：

   θ ← θ - η ∇ L( f_EMG(x_emg; θ), y_hat_vis )

   或更保守：只更新归一化统计量（running mean/var）
             而非分类头 → 避免崩溃
```

**为什么这招强**：
- 视觉在操作过程中**持续提供自监督信号**（"你现在抓着球"）
- EMG 解码器**跟着当前疲劳状态在线校准** → 缓解分布漂移
- **这是"用视觉稳定 EMG"最本质的机制**（不是加权，是重校准）

**风险**：伪标签错误会污染模型 → 必须加**置信度门限 + 保守更新（小 η、只更新统计量）**。

---

### 机制 5：**时序稳定化**（Temporal stabilization）

- **滞回 + 最短保持时间**（命令切换需连续 N 帧支持）
- **一欧元滤波**（one-euro filter）在命令空间平滑
- 视觉检测到"抓握已稳定" → **锁定命令**（latch），直到视觉检测到松开

**评价直接可见**：命令**抖动次数/秒** 应显著下降。

---

## 三、⭐ 我推荐的三层方案（可做成递进消融）

| 层 | 机制 | 解决 | 实现难度 | 论文价值 |
|----|------|------|---------|---------|
| **L1** | 状态门控 + 伪影冻结 + 时序滞回 | 运动过程中的抖动 | 低 | 工程基线 |
| **L2** | 可靠性自适应加权 + 视觉先验兜底 | 伪影期误触发、输出乱跳 | 中 | **主贡献** |
| **L3** | 视觉锚定在线自适应（TTA）| **疲劳导致的漂移** | 中高 | **最有新意** |

**建议先做 L1+L2**（能拿到可信的稳定性提升），L3 作为进阶（如果时间够，它是论文亮点）。

---

## 四、⭐ 怎么证明"更稳了"（评价协议）

**光看分类准确率是证明不了的**——必须用时序/控制指标 + 长时程协议：

| 指标 | 含义 |
|------|------|
| **误触发率** | 静息时误判为发力（假肢乱动的直接原因）|
| **漏触发率** | 发力时未识别 |
| **命令抖动次数 / 秒** | 输出在相邻类别间跳变的频率 ← 稳定性核心 |
| **onset 延迟 (ms)** | 从意图到输出（不能因平滑而变慢）|
| **性能随时间的衰减** | ⭐ **关键**：连续运行 30–60 分钟，看准确率/误触发随时间变化 |

**最有说服力的实验**：
```
连续长时程协议（30–60 min，含多轮抓取-移动-放下）
   对比三条曲线随时间的衰减：
     ① EMG only          → 随疲劳明显衰减
     ② EMG + L1/L2       → 衰减变缓
     ③ EMG + L3(TTA)     → 衰减最平缓
```
→ **"视觉让性能不随时间崩塌"比"视觉让准确率高 2 个点"有说服力得多。**

## 五、⚠️ 坑与权衡

| 坑 | 说明 | 对策 |
|----|------|------|
| **视觉延迟** | 视觉 5–20 ms，若融合在慢循环会拖累控制 | 多速率：EMG 30 Hz 实时，视觉 10 Hz 异步更新"上下文" |
| **伪影检测误报** | 误判伪影 → 频繁冻结 → 控制变迟钝 | 滞回 + 只在强证据时冻结 |
| **视觉先验太强** | 模型只学 shape→抓握，忽略 EMG（捷径学习）| 训练时**随机丢弃视觉**（模态 dropout，如 20–30%）|
| **TTA 崩溃** | 伪标签错误累积 → 模型退化 | 置信度门限 + 只更新统计量 + 周期性回滚 |
| **标注泄漏** | 实验里物体已知 → shape 有"作弊"嫌疑 | 加**遮挡/出画**场景，或让受试者自选物体 |
| **训练/推理不一致** | 训练用完整序列，推理用在线流 | 一致性检查 + 因果（causal）结构 |

---

## 六、一句话回答你

> **"融合提升稳定性"的正确形态不是"把两个模态加权平均"，而是三种分工：**
> **① 视觉当"门"**（何时信任 EMG → 伪影期冻结/保持）
> **② 视觉当"先验"**（让输出不乱跳 → 贝叶斯先验兜底）
> **③ 视觉当"锚"**（在线伪标签 → 让 EMG 解码器随疲劳重校准）
> 而**评价必须换成时序指标 + 长时程衰减曲线**——"抖动次数下降、性能不随时间崩塌"才是"更稳"的证据。
