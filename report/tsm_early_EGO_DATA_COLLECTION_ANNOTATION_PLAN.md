# 头戴 ego 数据采集与自动标注方案（假肢交互场景）

> 核心结论：**不需要逐帧人工标注接触，也不需要标注抓握姿势**
> 方法：**用实验设计（提示时序 + EMG）让标签自动生成**

## 1. 为什么能自动？—— 标签来自"实验设计"而非"事后标注"

**关键思路**：你**控制**实验流程，所以**你知道每个时刻发生了什么**，程序记录下来就是标签。

```
实验流程（每个 trial）:
  t0  屏幕显示「请抓 圆柱」        → 标签: object=cylinder, grasp_type=power
  t1  提示音「开始」              → 标签: phase=approach 开始
  t2  用户手接触物体（记录时刻）   → 标签: phase=grasp 开始  ← 接触起点
  t3  提示音「松开」              → 标签: phase=release 开始
  t4  回到静止                    → 标签: phase=idle
```

**程序自动写出**（不需要人看视频）：
```json
{
  "trial_id": 7,
  "object": "cylinder",
  "grasp_type": "power",
  "t_prompt": 12.34, "t_start": 13.20,
  "t_contact": 14.05, "t_release": 16.30, "t_end": 17.10
}
```

**然后按时间窗切帧 → 自动给每帧打标签**：
```
[t_start,   t_contact)  →  no_contact   （伸手阶段 = 困难负样本！）
[t_contact, t_release]  →  contact      （抓握阶段 = 正样本）
(t_release, t_end]      →  no_contact   （松开后 = 负样本）
```

---

## 2. ⭐ 如何确定"接触时刻"（t_contact）——4 种方法

这是唯一的技术难点。按精度/成本排：

| 方法 | 做法 | 精度 | 成本 | 推荐 |
|------|------|------|------|------|
| **A. 提示时序** | 提示"抓"后固定延迟（如 0.8s）视为接触 | 中 | **¥0** | ⭐⭐ 快速起步 |
| **B. EMG onset** ⭐ | EMG 幅值突增 = 抓握意图开始 | **较高** | ¥0（你已有 EMG）| ⭐⭐⭐ **推荐** |
| **C. 视觉运动线索** | 手-物相对运动**停止** ≈ 接触 | 高 | ¥0 | ⭐⭐ 可作校验 |
| **D. 物理传感器** | 物体下压压力/开关 | 最高 | ¥50–200 | ⭐ 可选 |

**建议组合**：**B（EMG onset）为主 + C（视觉运动）校验**
- EMG onset 检测很成熟（幅值阈值 / Teager-Kaiser 能量）
- 视觉上"手与物体不再相对运动"是接触的强线索

**示例（EMG onset 自动检测）**：
```python
# 用 EMG 包络检测抓握起点
env = np.abs(hilbert(emg))            # 解析信号包络
thr = baseline_mean + 3 * baseline_std
t_contact = first_index(env > thr)    # 首次超阈 = 抓握开始
```

## 3. ⭐ 抓握姿势：不需要标注

| 你想要的 | 标签来源 | 人工 |
|---------|---------|------|
| **抓握类型**（5 类） | **物体 → 抓握映射**（圆柱→power，球→spherical...）| **0** |
| 手指关节角（连续） | ❌ 你不做姿态回归 → **不需要** | — |

**物体-抓握映射表**（采集程序里写死，自动带标签）：
```python
GRASP_MAP = {
    "sphere":    "spherical",
    "cylinder":  "power",
    "prism":     "tri_digital",
    "handle_box":"lateral",
    "thin_plate":"bi_digital",
}
```

**所以"抓握姿势"零标注**——因为**是你指定被试抓什么**。

## 4. 头戴 ego 相机的优势（针对你的场景）

| 优势 | 说明 |
|------|------|
| **物体在画面中** | 用户要看物体才能抓 → 物体大概率进入视野 |
| **贴近真实假肢使用** | 假肢用户的视角就是第一人称 |
| **手-物同时可见** | 伸手抓握时，手和物体都在视野内（接触检测的关键）|
| ⚠️ 风险 | 手可能**出画**或**被遮挡** → 采集时提示"动作放慢、手保持在视野中央" |

## 5. 采集程序设计（自动标签是核心）

```
┌─────────────────────────────────────────────────┐
│  采集程序（一个屏幕 + 摄像头 + EMG + 提示音）      │
├─────────────────────────────────────────────────┤
│ 1. 被试信息录入（ID/年龄/性别/会话）              │
│ 2. 循环每个 trial:                               │
│    a. 显示物体图 + 名称（1s）                     │
│    b. 提示音「开始」→ 记录 t_start（打 mark）      │
│    c. 用户伸手 → 抓 → 保持（程序持续录制）        │
│    d. 提示音「松开」→ 记录 t_release              │
│    e. 静止 2s → 记录 t_end                       │
│    f. 写入一条 trial JSON（含上述时间戳）         │
│ 3. 会话结束：输出 trials.json + 视频 + EMG 文件   │
└─────────────────────────────────────────────────┘
```

**关键：提示音同时写入 EMG 的 AUX 通道**（硬件同步），这样：
- 视频时间 ↔ EMG 时间可对齐
- 提示时刻在两边都有标记

### 数据产物
```
session_P03/
├── trials.json          ← 自动生成的标签（含时间戳）
├── video.mp4            ← 头戴相机全程录像
├── emg.npy              ← 6ch × 2kHz（含 AUX 标记）

```

## 6. 训练数据怎么切（全自动脚本）

```python
# 伪代码：从 trials.json + 视频 自动生成训练集
for trial in trials:
    frames = read_video(trial.video, fps=30)
    for t, frame in enumerate(frames):
        ts = t / 30.0
        if trial.t_start <= ts < trial.t_contact:
            label = "no_contact"          # 伸手阶段（困难负样本）
        elif trial.t_contact <= ts <= trial.t_release:
            label = "contact"             # 抓握阶段
        elif ts > trial.t_release:
            label = "no_contact"          # 松开后
        else:
            continue                      # 静止期不采
        crop = detect_hand_object(frame)  # 裁手-物区域
        save(crop, label, object=trial.object)
```

→ **零人工，一键生成几千到几万张带标签的图**。

## 7. 唯一需要人工的地方（很少）

| 项 | 工作量 | 说明 |
|----|--------|------|
| **抽查质检** | 5–10% | 看标签是否合理 |
| **剔除异常 trial** | 少量 | 做错、手出画、失败 |
| **（可选）边界修正** | 少量 | EMG onset 偏了 ±0.2s 时手工微调 |

**预估**：12 人 × 2 会话 × 100 trial ≈ 2400 trial，人工质检约 **2–4 小时**（不是几天）。

---

## 8. ⚠️ 三个必须提前设计好的点

| 点 | 为什么重要 | 做法 |
|----|-----------|------|
| **① 同步** | 视频/EMG/提示时间戳要对齐 | 提示音同时打 EMG AUX + 视频里可听到 |
| **② 困难负样本** | 只标"远近"模型学不会 | 伸手阶段（手离物体很近但没接触）**必须采** |
| **③ 手不出画** | 头戴视角易丢手 | 提示被试动作放慢；采集时监控"手是否在画面" |

---

## 9. 一句话总结

> **不用逐帧标注，也不用标抓握姿势。**
> - **接触标签** ← 提示时序 + **EMG onset** 自动切分
> - **抓握类型** ← "抓哪个物体"自动决定（物体→抓握映射）
> - **物体标签** ← 采集程序自动记录
> - **你只需**：设计好实验流程 + 抽查 5–10% 质检

**毕设难点从"标注"转移到"实验设计"**——而这是可控的。
