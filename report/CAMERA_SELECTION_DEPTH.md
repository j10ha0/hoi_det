# 相机选型 v2：SDK 允许后（深度相机可行）

> 更新：**厂商 SDK 可以接受**，只要提供**实时接口**。
> 你提到看过 **奥比中光 Gemini 双目深度** —— 这个方向对，而且比 UVC 方案更好。

---

## 一、⭐ 为什么深度相机对你这个任务更好

```
单目方案：RGB → MediaPipe 2D 关键点 → 【2D→3D 需要猜深度】
          → 关节角有尺度歧义，精度受限

深度方案：RGB → MediaPipe 2D 关键点
          ↓ 用【对齐后的深度图】取值
          21 个 3D 关键点（相机坐标系，真尺度）✓
          ↓
          关节角 = 相邻骨段夹角（MCP / PIP / DIP）
```
**→ 有深度后关节角是真实尺度，不用猜；GPU 也不必跑 WiLoR 那种重模型。**

---

## 二、⚠️ 一个关键技术点：**手是"弱纹理表面"**

双目立体匹配靠**纹理**找对应点 —— 而**皮肤纹理很弱** → **纯被动双目的深度图会有大量空洞**。

**解决**：选**带主动 IR 投射器**的型号（结构光/散斑辅助）。

| 类型 | 对手部 | 说明 |
|------|--------|------|
| **纯被动双目** | ❌ 最差 | 皮肤无纹理 → 深度大量空洞 |
| **主动双目**（带 IR 投射）| ✅ **好** | RealSense D435i / Orbbec Gemini 330 系列 |
| **结构光** | 🔶 近距好 | Astra 2；远距差、强光失效 |
| **iToF** | ✅ 好 | Femto 系列，但贵 |

**→ 建议：选带主动 IR 投射的双目，别选纯被动双目。**

## 六、⭐ 实际做法建议

```
第一步  先用手边摄像头（或笔记本自带）把 MediaPipe 21 关键点 + 关节角算好
        → 纯 RGB 流水线，任何相机都能跑
第二步  买相机后，只需加一段：把 2D 关键点 + 深度图 → 3D 关键点
        （pyrealsense2 / pyorbbecsdk 各 ~20 行）
第三步  关节角改为在 3D 上算 → 精度提升，且有真实尺度
```

**代码分层设计**（换相机只改最底层 20 行）：
```
camera.py       ← 唯一与相机相关的部分（UVC / RealSense / Orbbec 三选一）
hand_pose.py    ← MediaPipe 关键点（与相机无关）
joint_angle.py  ← 关节角计算（2D 或 3D，与相机无关）
visualize.py    ← 显示（与相机无关）
```
