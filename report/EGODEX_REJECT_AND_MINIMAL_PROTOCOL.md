# EgoDex 不适合 + 你的最小采集方案

> 你的观察：① 只用单手 ② 动作太快 ③ **没有"非对准 → 转向对准"的过程** ④ 像自动驾驶
> 你的核心任务：**通过物体 shape + 目标位置，调整腕旋，让手对准物体**
> 你的诉求：**自己采数据，但要简单，不要像 EgoDex 那么复杂**

---

## 一、你的判断是对的 —— 而且这是个「结构性错配」

### 1.1 精确定位问题在哪

| 你看到的 | 根本原因 |
|---------|---------|
| 动作太快 | 专家演示是**熟练、连续、无停顿**的动作 |
| **没有"非对准→对准"过程** ⭐ | 人类伸手时会**预先设定好手型**（pre-shaping），"对准"在**伸手过程中就完成了**，不会表现为一个独立的"发现错位→修正"阶段 |
| 像自动驾驶 | 这类数据集是**模仿学习**数据 = **开环最优轨迹**；没有错误、没有纠错、没有"想一想再改" |
| 双手 | EgoDex 面向灵巧操作（系鞋带、叠衣服），大量双手任务 |

### 1.2 ⭐ 最本质的一条

> **你的任务本质是「闭环误差修正」：当前姿态与目标姿态有偏差 → 计算并执行修正。**
> **EgoDex 记录的是「开环熟练轨迹」：专家从没错过，所以数据里没有"错"可学。**

**这两种数据的分布根本不同** —— 不是"数据不够"，而是"数据里没有你要的现象"。

### 1.3 一个技术性解释

人的运动控制里，「对准」通常发生在**伸手阶段**（transport phase），手在到达物体时已经摆好姿势。
所以录像里看到的是**流畅的一气呵成**，而不是"到了→发现不对→转过来"。

**→ 除非有人为设计（故意制造错位），这类数据永远不会包含你要的过程。**

## 二、⭐ 好消息：你的数据可以设计得**极简**

**关键洞察：既然错位是"设计出来的"，那么"正确修正方向"也就是设计已知的
—— 标签来自实验设计，不需要 IMU、不需要人工标注。**

### 2.1 最小采集协议（"对准修正"数据集）

**核心设计：故意让手从错位开始**

```
每个 trial 三阶段（要求受试者【放慢】，每个阶段停 2–3 秒）：

  ① 保持错位 (2–3 s)     手张开但掌心朝向不对，悬在物体附近
        ↓
  ② 旋转对准 (2–3 s)     只转腕（旋前/旋后），直到掌心对准物体
        ↓
  ③ 抓握     (1–2 s)     抓上去
```

**因子设计**（三个因子决定标签）：

| 因子 | 取值 | 数量 |
|------|------|------|
| 物体形状 | 你的 5 种 | 5 |
| **物体方位**（相对手的方位）| 正前 / 左前 / 右前 / 左 / 右 / 正后… | 6–8 |
| **初始掌心朝向** | 朝下 / 朝上 / 朝左 / 朝右 | 3–4 |

**→ 每个组合的「正确修正方向」由设计直接决定 = 标签**（不用测、不用标）

### 2.2 为什么必须变化「初始掌心朝向」⭐

这是**最关键的一条**：
- 如果只在一个固定掌心朝向下采 → 模型会学"物体位置 → 转向"，**退化成查表**
- **同一物体位置 + 不同初始朝向 → 需要不同的修正** → 模型才必须**真的看懂图像**

### 2.3 工作量估算（很小的规模）

```
每 trial ≈ 8 秒（含准备）
150 trials ≈ 20 分钟录制  → 约 3.6 万帧（30fps）
```
**这已经够训一个"图像 → 修正方向"的小模型了。**
（对比 EgoDex：829 小时、2 TB —— 你完全不需要）

### 2.4 标签定义（两种粒度）

| 粒度 | 标签 | 来源 |
|------|------|------|
| **粗（推荐先做）** | 旋前 / 旋后 / 不需转（3 类） | 由设计几何直接定 |
| 细 | 修正角度（连续，度） | 由设计几何算出，或 IMU 实测 |

**先做粗的**（3 类分类），最容易验证任务可学。

## 五、我建议的极简路线（4 步）

```
Step 1  采 1 个被试 / ~150 trials / 20 分钟
        · 物品 5 种 × 方位 6–8 × 初始朝向 3–4
        · 每 trial 三阶段慢速：错位保持 → 旋转对准 → 抓握
        · 只录【单目 RGB】（头戴或支架固定）
        · 标签 = 设计已知的"正确修正方向"

Step 2  用 MediaPipe 手部关键点做人手可见性/质量过滤（自动，不用人标）

Step 3  训小模型：单帧 RGB → {修正方向(3类), 抓握类型(5类)}
        · 预训练骨干 + 两个分类头，单卡几小时
        · 关键消融：有/无"初始朝向"多样性（验证是否退化成查表）

Step 4  若有效 → 扩到多被试 / 加 EMG 触发，拼成完整控制回路
```
