# 相机选型：固定机位 + USB UVC + 实时关节角度标定（预算 ≤2000 元）

> 需求：**固定机位** · **USB UVC 连电脑** · **实时手部关节角度标定** · **≤2000 元** · 淘宝可买

---

## 一、⭐ 先明确：你的需求会排除掉大部分"研究标配"相机

| 需求 | 影响 |
|------|------|
| **USB UVC** | ⚠️ **这是硬约束** —— 具身智能论文里最常见的 **RealSense / ZED / Orbbec 都不是 UVC**，需专用 SDK |
| **固定机位** | ✅ 不需要防抖/头戴 → 可选范围大 |
| **实时关节角** | 分辨率 1080p 够；**需要 ≥30 FPS**；手在画面里要够大 |
| **≤2000 元** | 排除绝大多数深度相机 |

**→ 符合"研究级 + UVC + ≤2000"的，就是「工业 USB3 UVC 相机 + C 口镜头」这一路。**

## 三、⭐ 镜头怎么选（最容易忽略、也最影响效果）

工业相机**机身不含镜头**，要按你的**工作距离**选焦距。

**近似公式**：
```
f ≈ (传感器宽度 × 工作距离) / 期望视野宽度
```

**举例**：传感器 1/2"（宽 6.4 mm），相机放在手前方 **0.6 m**，
想让画面覆盖 **0.4 m** 宽（手 + 一点余量）：
```
f ≈ 6.4 × 0.6 / 0.4 ≈ 9.6 mm   → 买 8 mm 或 12 mm 镜头
```

**常用焦距参考**（1/2" 传感器，手部工作距离 0.4–0.8 m）：
| 工作距离 | 覆盖 ~0.4 m 视野所需焦距 |
|---------|----------------------|
| 0.4 m | ~6 mm |
| 0.6 m | ~8–12 mm |
| 0.8 m | ~12–16 mm |
| 1.0 m | ~16 mm |

**建议**：买 **6–12 mm 可调或两个定焦**，实测后固定。
**别买太广的**（如 2.8 mm）→ 手在画面里太小，关节角精度下降。

## 四、关键参数检查清单（买前逐条核对）

| 参数 | 建议 | 为什么 |
|------|------|--------|
| ⭐ **是否 UVC 免驱** | **必须确认** | 否则 OpenCV 读不到 |
| **接口** | **USB 3.0** | USB2 带宽不够高帧率/高分辨率 |
| **快门** | **全局快门**（手在动）| 卷帘快门会拖影，影响关节角 |
| **分辨率** | 1080p ~ 5MP | 再高就要降采样才能实时 |
| **帧率** | **≥30，最好 60** | 关节角曲线平滑 |
| **镜头接口** | **C / CS mount** | 便于换镜头调视野 |
| **彩色/黑白** | 彩色（若要用肤色/MediaPipe）| 黑白便宜但通用性差 |
| **供电** | 多数工业相机**无自带电池**，需 USB 供电 | 确认电脑 USB3 口供电够 |
