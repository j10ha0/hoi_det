# 纯视觉方案：抓握形态识别 + 接近判断（毕设落地版）

> 决策：**放弃 ToF**，改用视觉判断「是否接近」+「抓握形态」
> 理由：毕业时间紧；ToF 需调驱动、做同步电路；视觉零硬件成本、MediaPipe 现成
> 日期：2026-09-15　目录：`proj/tsm_visual/`

---

## 1. 为什么这个决定是对的

| 维度 | ToF 方案 | **视觉方案（选定）** |
|------|---------|-------------------|
| 硬件 | VL53L5CX + MCU + 腕带 + 驱动调试 | **用现有摄像头** |
| 同步电路 | 需自己做（EMG↔ToF 时间对齐）| **软件时间戳即可** |
| 上手时间 | 2–4 周（含调驱动）| **1–2 天** |
| 信息量 | 8×8 距离（认不出物体）| **21 关键点 + 颜色（能认抓握形态）** |
| 结论 | 时间不够 | ✅ **适合毕设** |

## 2. 技术架构

```
摄像头 (USB / 头戴)
   │
   ├─ 手部: MediaPipe HandLandmarker → 21 关键点 (含米制 world 坐标)
   │
   └─ 物体: 目标检测 (YOLO) 或 固定区域/手动框
   │
   ▼
特征提取
   ├─ 手指弯曲角 (MCP-PIP-DIP 关节角)
   ├─ 伸展度 (指尖-腕距 / 掌长)
   ├─ 捏合距离 (拇指↔食指/中指指尖距)
   └─ 手-物距离 (包围盒中心距, 归一化)
   │
   ▼
输出
   ├─ 抓握形态: OPEN / POWER / PINCH / TRIPOD / HOOK / REST
   └─ 接近与否: bool
   │
   ▼
与 EMG 融合 → 触发抓握（视觉=该抓了, EMG=现在抓）
```

## 3. 两阶段实施（按时间选）

### 阶段 A：规则法（1–2 天，先跑通）
- 用**阈值规则**从关键点直接分类（已实现：`vision_grasp_recognition.py`）
- **必须先做**：用你自己拍的手势图**标定阈值**
- 局限：对**手掌朝向**敏感（3D 关节角会随手腕转动变化）

**实测暴露的问题**（重要）：
```
测试图（两只张开的手）→ 手0 判 OPEN、手1 判 REST  ← 误判！
原因: 阈值 (curl>150=直, <110=屈) 未经标定；且拇指 148° 刚好落在边界
```
→ **规则法一定要标定，或直接用阶段 B。**

### 阶段 B：分类器法（推荐，3–5 天）
- 采集几百张手势图（每个手势 50–100 张，多角度/多光线）
- 用 MediaPipe 提 21 点 → **归一化特征** → 训一个小分类器（MLP / SVM / 随机森林）
- **优势**：鲁棒（自动学阈值）、可输出置信度
- 特征建议（应对朝向问题）：
  - 每指关节角（4×5=20 维）
  - 指尖到掌心的距离（5 维，**对旋转不敏感**）
  - 指尖间距离（拇指-食/中/无名/小，4 维）
  - **相对**特征（除以掌长做尺度归一化）

## 5. 与 EMG 融合（毕设核心）

| 方案 | 做法 | 难度 |
|------|------|------|
| **决策级融合** ⭐ | 视觉出"抓握形态"，EMG 出"动作意图"→ 融合 | 低 |
| 特征级融合 | 视觉特征 + EMG 特征 → 拼接 → 分类 | 中 |
| 因果条件化 | 视觉当 context，条件化 EMG 分支 | 中（已有代码）|

**推荐**：先做**决策级融合**（易实现、好写论文），再升级。

### 5.1 状态机（接近触发 + EMG 确认）
```
[IDLE] 手远离物体
   ↓ 视觉: 手-物距离 < d1
[APPROACH]
   ↓ 视觉: 距离 < d2 且 EMG 幅值 > 阈值
[TRIGGER] → 执行视觉判定的抓握形态
[GRASP]
   ↓ EMG 放松 / 距离增大
[RELEASE] → IDLE
```

## 6. ⭐ 毕设可写的创新点（时间紧但要够用）

| 点 | 说明 | 数据支撑 |
|----|------|---------|
| **① 视觉+EMG 双条件触发** | 降低误触发 vs 纯 EMG | 误触发率对比 |
| **② 视觉退化时 EMG 兜底** | 遮挡/暗光下融合更稳 | 分层评测 |
| **③ 视觉辅助的抓握形态选择** | 免去手动切换 | 准确率 + 用户研究 |
| **④ 融合有效性消融** | 去掉视觉/EMG 各掉多少 | 消融表 |

**最小可交付**：① + ④（够一个毕设）

## 8. 风险与对策

| 风险 | 对策 |
|------|------|
| **手掌朝向影响关节角** | 用**相对特征**（指尖-掌心距/掌长），或数据增强（旋转）|
| 自遮挡 | 提示被试"正对相机"；或加第二视角 |
| 视觉延迟 | 视觉低频（10–15 fps 够）；EMG 独享实时 |
| 光照变化 | 采集时覆盖多光照；或加直方图均衡 |
| **融合无效** | **先做 2–3 人预实验**验证（见下）|
