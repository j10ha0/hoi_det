# 场景条件化 EMG 流式模型（Scene-Conditioned EMG）

> 按最新思路实现：**EMG 保持流式**（实时主导），**视觉只做低频抽帧**提供"场景上下文"，融合进 EMG 模型。

---

## 1. 架构（相比"视频流式"大幅简化）

```
┌── EMG 分支（流式，因果 TCN + 状态缓存）──────────────┐
│   每个 EMG 小块 (如 40ms/80点) → 因果卷积堆叠        │
│   → h_e(t) (B, L, D)                                │   ← 实时主导
└──────────────────────────────────────────────────────┘
                    ↓ query
┌── 场景条件（视觉，低频抽帧，无时序）──────────────────┐
│   每 N ms 抽 1 帧 → 图像编码器 → s (B, D_scene)       │   ← 异步更新（2~5 Hz）
│   缓存为「当前场景上下文」，供 EMG 每步查询           │
└──────────────────────────────────────────────────────┘
                    ↓ key / value
   cross-attention（EMG query 场景）→ 条件化特征 → 分类/回归头
```

**两个线程/频率解耦**：
| 分支 | 频率 | 延迟要求 |
|------|------|---------|
| EMG | 每 10–50 ms 一步 | **严格实时**（控制信号）|
| 视觉（场景）| 每 200–500 ms 抽 1 帧 | **宽松**（场景变化慢）|

## 2. 为什么这样更好

| 维度 | 视频流式 Transformer（上一版）| **场景条件化 EMG（本版）** |
|------|---------------------------|------------------------|
| 模型规模 | 24.9M | **5.91M**（小 4 倍）|
| 视觉复杂度 | 需视频 KV cache + 因果时空注意力 | **单帧图像编码即可** |
| 实时性 | 视觉也要低延迟 | 视觉可慢（抽帧），EMG 独享实时预算 |
| 与 EMG 融合 | 逐帧对齐，复杂 | **场景作为 context**，语义清晰 |
| 维度含义 | 视觉特征 vs EMG 特征拼接 | **"看到什么物体/场景" → 指导"该做什么动作"** |

对齐了之前调研的结论：**视觉提供"物体/场景上下文"，EMG 提供"发力/意图"**——两者回答不同问题，不需要视觉也做到逐帧流式。

## 3. 验证结果（全部通过）

```
[场景] 帧 (2,3,224,224) -> 场景向量 (2,128)
[整段] logits=(2,640,6)
[流式] logits=(2,640,6) | 与整段差异 5.960e-07   ✓ EMG 因果 TCN 流式一致
[条件] 换场景后输出变化 0.1898                  ✓ 场景条件确实生效
[延迟] EMG 流式一步(80点/40ms) 11.37 ms          ✓ 实时
[规模] EMG 0.26M + 场景 5.55M + 融合头 0.10M = 5.91M
```

- **流式一致性**：整段 vs 逐块流式差异 6e-07（因果卷积 + 历史缓存正确）
- **场景生效性**：换一张场景帧，输出变化 0.19（证明条件化真的起作用，不是摆设）
- **延迟**：EMG 一步（40 ms 数据）耗时 **11.37 ms** —— 远低于 40 ms 预算
- **规模**：**5.91 M**（其中场景编码器占 5.55M，可换更小 backbone 再降）

## 4. 用法

```python
from scene_conditioned_emg import SceneConditionedEMG

model = SceneConditionedEMG(
    emg_ch=16, d_model=128, num_classes=6,
    scene_backbone="vit_tiny_patch16_224",   # 可换 DINOv2 / CLIP / resnet18
).cuda()

# ---- 训练（整段）----
logits = model(emg)                     # emg: (B, 16, L) -> (B, L, 6)

# ---- 部署：两线程 ----
# 视觉线程（2~5 Hz）
model.update_scene(frame)               # frame: (B,3,224,224)，异步、随时可调用

# EMG 主线程（每 10~50 ms）
model.reset_cache()
logits_chunk = model.stream_step(emg_chunk)   # emg_chunk: (B,16,Lc)
```

## 5. 可调项

| 项 | 选项 | 影响 |
|----|------|------|
| `scene_backbone` | `vit_tiny`(5.5M) / `resnet18` / `DINOv2` / `CLIP` | 场景语义质量 vs 规模 |
| 抽帧频率 | 1–5 Hz | 场景更新及时性 vs 算力 |
| 融合方式 | **cross-attention**（当前）/ FiLM 调制 / 拼接门控 | 条件注入强度 |
| `d_model` | 64/128/256 | EMG 分支容量 |

**换更小的场景 backbone**（如 `resnet18`）可把总规模压到 ~5M 以内。
