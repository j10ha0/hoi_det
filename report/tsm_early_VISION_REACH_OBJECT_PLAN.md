## 2. 物体与抓握模式（直接复用 HANDdata 的设计）

| 物体形状 | 抓握模式 | 说明 |
|---------|---------|------|
| **Sphere 球** | Spherical 球状抓 | 全掌包覆 |
| **Cylinder 圆柱** | Power 强力抓 | 全掌握 |
| **Triangular Prism 三棱柱** | Tri-digital 三指抓 | 拇+食+中 |

**材质**：木 / 铝（可增加分类难度）
**任务**（复杂度递增）：Static → Pick-and-Lift → Pick-Lift-and-Move

## 3. 技术方案

### 3.1 手到达检测（reach detection）
```
摄像头帧
  → 手部检测（MediaPipe Hands 只用「掌心位置/包围盒」，不用关节角）
  → 物体框（来自 3.2 的分类/检测）
  → 手-物距离 d(t)（像素距离，用掌长归一化消除远近影响）
  → 状态机:
       d > d1          → FAR (未到达)
       d2 < d < d1     → APPROACHING (接近中)
       d < d2 且持续N帧 → REACHED (已到达) ← 触发抓握候选
```

**要点**：
- 用 **掌长**（腕→中指MCP，米制）做尺度归一化，消除"人离相机远近"的影响
- 加**时间去抖**（连续 N 帧满足才算到达）

### 3.2 物体形状判断（object shape recognition）
**两条路，建议先 A 再 B：**

| 方案 | 做法 | 难度 | 说明 |
|------|------|------|------|
| **A. 图像分类** ⭐ | 裁剪物体区域 → 5 类分类（ResNet18/EfficientNet 微调）| 低 | 物体是标准化的，分类够用 |
| B. 目标检测 | YOLO 直接出「物体框 + 类别」| 中 | 更接近真实场景（多物体）|

**方案 A 的实施**：
```python
# 用 torchvision 预训练 ResNet18 微调（5 类）
model = torchvision.models.resnet18(weights="IMAGENET1K_V1")
model.fc = nn.Linear(512, 5)          # 5 种形状
# 数据：每类 100–500 张（多角度/光照/背景）
```

**数据采集建议**：
- 10 个物体（5 形状 × 2 材质）× 每物体 50–100 张 = **500–1000 张**
- 覆盖：不同角度、距离、光照、背景
- 划分：**按物体实例划分**（避免同物体同时出现在训练/测试 → 虚高）

## 4. 与 EMG 融合（毕设核心）

```
视觉分支:  物体形状 → 抓握模式 + 手到达状态
                ↓
EMG 分支:  6ch @2kHz → 抓握意图/发力
                ↓
融合 → 触发抓握（视觉="该抓了/抓什么"，EMG="现在抓"）
```

| 融合层级 | 做法 | 难度 |
|---------|------|------|
| **决策级** ⭐ | 视觉给"抓握模式"，EMG 给"触发时刻" | 低 |
| 特征级 | 视觉特征 + EMG 特征拼接 | 中 |
| 因果条件化 | 视觉 context 条件化 EMG | 中 |

**状态机（推荐）**：
```
[IDLE] 手远
  ↓ 视觉: APPROACHING
[APPROACH]
  ↓ 视觉: REACHED 且 EMG 幅值 > 阈值（意图确认）
[TRIGGER] → 执行视觉判定的抓握模式
[GRASP]
  ↓ EMG 放松 / 手远离
[RELEASE]
```

## 5. ⚠️ 关于 HANDdata 的一个重要限制

**HANDdata 没有 RGB 图像**（只有雷达/ToF + 手套 + IMU）。

所以：
| 能复用 HANDdata 的 | 不能复用（要自己采）|
|-------------------|-------------------|
| ✅ 物体设计（5 形状 × 2 材质）| ❌ 图像（它没有相机）|
| ✅ 抓握模式映射 | ❌ 你的视觉数据 |
| ✅ 任务设计（static/pick-lift/move）| |
| ✅ 实验流程与规模参考 | |

**结论**：**实验设计照抄它，图像数据自己拍**（这反而是你的贡献——"纯视觉版"）。
