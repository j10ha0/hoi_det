# EgoTactile 批量测试结果（ego 视角：手 → 最近物体 → 位置 + shape）

> 测试日期：2026-09-21
> 数据：**EgoTactile**（ICML 2026 spotlight）bare_hand 子集
> 目的：验证「**检测离手最近的物体，并输出其位置与 shape**」这条链路

## 1. 为什么用 EgoTactile

| 特性 | 价值 |

## 2. 测试配置

```
15 个物体 × 2 帧（视频的 40% 与 65% 处）= 30 帧
物体: Apple, Banana, Carrot, CestbonWater-555ml, Clip, CocaCola-330ml,
      CocaCola-500ml, Dumbbell, LaysChips-Tube, Orange, Pepsi-330ml,
      SamyangCupNoodles, Sprite-500ml, TennisBall, Tomato

流水线:
  ① WiLoR        → 手心位置 + 掌心法向
  ② FastSAM      → 全图分割 → 候选区域
  ③ 过滤         → 面积 / 触边(背景) / 与手重叠 / 太贴手
  ④ 方向筛选     → 物体方向与掌心法向夹角 < 60°（符号自动选择）
  ⑤ 取最近       → 目标物体
  ⑥ PCA          → 主轴 + 特征值比 → shape 判定

判定标准（可定量）:
  · 球类 (Apple/Orange/TennisBall/Tomato) → 应判「无主轴」
  · 其他 (罐/瓶/香蕉/胡萝卜/哑铃/夹子/管/杯面) → 应判「有主轴」
```

## 3. ⭐ 结果

| 指标 | 数值 |
|------|------|
| 总帧数 | 30 |
| **成功定位物体** | **23（77%）** |
| 未检出手（WiLoR 失败）| 2（Dumbbell 两帧）|
| 无合格候选 | 5 |
| **主轴判定一致率** | **18/23（78%）** |

### 按"手遮挡程度"分组

| 手物重叠 | 帧数 | 一致率 |
|---------|------|--------|
| **0–10%**（物体清晰可见）| 11 | **91%** |
| 10–50% | 3 | 33%（样本少）|
| 50–80% | 6 | 100% |
| **>80%**（物体几乎被手挡住）| 3 | **33%** |

**结论**：
- ⭐ **物体清晰可见时（遮挡 <10%），判定一致率 91%** —— 链路可用
- ⚠️ **遮挡 >80% 时降到 33%** —— 因为分割会把"手"或"手+物体"当成物体
- **→ 应该过滤掉高遮挡帧**（这与之前"挑干净帧"的思路一致）

## 4. 典型成功案例

| 物体 | 真值 | 判定 | 备注 |
|------|------|------|------|
| CocaCola-330ml / 500ml | 圆柱（罐）| **中等长宽比(棱柱/盒)** | 罐的长宽比 ≈1.7，判定合理 |
| Pepsi-330ml | 圆柱 | 中等长宽比 | evr 0.26–0.29 |
| LaysChips-Tube | 圆柱管 | **细长(圆柱/长条)** | evr 0.10–0.12，最典型 |
| Orange / Apple / TennisBall / Tomato | 球 | **球/圆盘**（无主轴）| evr 0.79–0.92 → **自动跳过对准** ✓ |
| CestbonWater / Sprite / Clip / Banana | 瓶/小物 | 中等长宽比 | |

## 5. 典型失败案例（都是高遮挡）

| 帧 | 问题 | 现象 |
|----|------|------|
| Sprite-500ml_p0.40 | 手遮挡 **97%** | 判成「方块/矩形」evr 0.97 → **分割到的是手** |
| Tomato_p0.65 | 手遮挡 **89%** | 判成「中等长宽比」evr 0.29 → 手+物体糊成一团 |
| SamyangCupNoodles_p0.65 | evr 0.86 | 判成「不规则」|
| Dumbbell 两帧 | — | **WiLoR 未检出手**（哑铃较细长，手型特殊）|

## 6. 本次测试的结论与改进方向

### 已验证可行 ✅
1. **ego 视角下能定位"离手最近的物体"**（77%）
2. **物体清晰可见时 shape 判定可靠**（91%）
3. **球体自动识别为"无主轴"→ 跳过对准**（这是设计上的关键正确行为）
4. **圆柱/长条能正确给出主轴**（LaysChips-Tube evr 0.10 最典型）

### 需要改进 ⚠️
| 问题 | 改进 |
|------|------|
| **高遮挡帧失败** | ⭐ **加"手物重叠阈值"过滤**（遮挡 >60% 直接丢弃）|
| **WiLoR 偶尔检不到手** | 换/补 **MediaPipe**（2D，更稳）|
| **手可能被当成物体** | 用"与手 bbox 重叠" + "颜色/纹理相似度"联合排除 |
| 无物体 6D 位姿 | 只有图像平面轴向；需要 3D 时用 HOI4D |
