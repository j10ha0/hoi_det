## 二、⭐ 核心答案：对齐角是**几何量**，可以直接算

### 2.1 "对准"的严格定义

```
u = normalize( 物体中心 − 手中心 )     # 期望的掌心朝向（掌心应指向物体）
n = 掌心法向（由手部姿态决定）          # 当前掌心实际朝向

需要的旋转 = 把 n 转到 u 的那个旋转
```

投影到前臂长轴上，就得到**旋前/旋后角度**：

```python
# 手姿 R_hand (3x3)，物心 p_obj，手心 p_hand
u = normalize(p_obj - p_hand)
n = R_hand @ [0, 0, 1]              # 掌心法向（假设 Z 轴为掌心方向）
axis = normalize(cross(u, n))
theta = arccos(clip(dot(u, n)))      # 最小旋转角（轴角表示）

# 只要绕【前臂长轴】的分量 = 腕旋需要转的角度
forearm_axis = R_forearm @ [1, 0, 0] # 前臂长轴
theta_wrist = theta * dot(axis, forearm_axis)
# theta_wrist > 0 → 旋前；< 0 → 旋后；≈0 → 已对准
```

**这是**闭式几何解** —— 不是 RL，不是优化，就是向量运算。**

### 2.2 所以标签方案有两条（都不是 RL）

| 方案 | 标签怎么来 | 需要什么测量 | 特点 |
|------|-----------|-------------|------|
| **A. 解析几何** ⭐ | 用上式算出"需要转多少" | 手姿 + 物姿 | **学到的是"几何最优"**（可泛化到新物体）|
| **B. 模仿** | 学人**实际**转了多少（对时间求导得到腕旋角速度）| 手姿 | 学到的是"人的习惯" |

**推荐 A**：因为你要做的是"对准物体"，这是**几何任务**，解析标签最干净且能泛化。

## 三、⭐ 怎么测手姿和物姿？—— 最简方案：**贴两个标记**

**不需要 IMU、不需要 3D 手部重建网络、不需要仿真。**

```
【手背】贴一个 ArUco / AprilTag 小标记   → 解出手的姿态（含掌心法向）
【物体】贴一个 ArUco / AprilTag 小标记   → 解出物体的 6D 位姿
              ↓
      普通相机 + OpenCV（aruco 模块）
              ↓
      逐帧得到 R_hand, p_obj  → 代入公式 → 每帧的"需要的腕旋角"
```

**优点**：
- ✅ **完全自由动作**（无脚本、无提示）
- ✅ **零人工标注**（全自动）
- ✅ **不用 IMU**（避开了你不想做的 IMU 建模）
- ✅ **不用强化学习**
- ✅ **部署时不需要标记**（模型只看图像；标记仅用于**采集阶段造标签**）

**成本**：打印两张标记纸、贴上去。就是这个量级。

> ⚠️ 手背标记测的是**手背朝向**，掌心法向是它的反向（或需一个固定旋转外参）—— 标定一次即可。

## 四、⭐ 为什么**不需要**强化学习？

RL 的适用条件 vs 你的情形：

| RL 需要什么 | 你的情形 |
|------------|---------|
| **没有监督信号**（只能靠奖励试错）| ❌ **你有**：几何真值（掌心朝向 + 物体位置 → 唯一确定的旋转）|
| **动作序列 + 延迟奖励** | ❌ 你要的是"给定场景 → 一个角度"，是**一步映射** |
| **接触动力学 / 失败恢复** | ❌ 你说的场景是单次对准，不涉及序列博弈 |
| **样本效率低**（百万级交互）| ✅ 监督学习几千~几万帧就够 |

**结论**：
> **"需要转多少才能对准"是一个可以用公式算出来的量** →
> **直接算出来当标签，做监督学习即可，RL 是杀鸡用牛刀。**

**RL 只在什么情况下才值得**：如果要学的是**整段闭环策略**（"伸过去→发现不对→转→再抓→抓滑了重抓"），
那时才有序列决策和失败恢复。但**你现在的目标不是这个**。

## 五、⚠️ 三个必须注意的点

### 点 1：对准只对「有偏好抓握方向」的物体有意义
| 物体 | 对准是否有意义 |
|------|--------------|
| **球** | ❌ 无所谓 —— 任何朝向都能球抓，标签无意义 |
| 圆柱 / 棱柱 / 带柄盒 / 薄片 | ✅ 有意义（有可抓面/轴）|

→ **球体会成为"标签噪声源"**，需要单独处理（或从 H3 训练中排除，只用于 H2）。

### 点 2：要用「掌心指向物体」这个定义，还是「掌心对准可抓面法向」？
| 定义 | 优点 | 缺点 |
|------|------|------|
| **掌心 → 物体中心** ⭐ | 简单、对所有物体通用、易算 | 对某些抓握不是几何最优 |
| 掌心 → 物体可抓面法向 | 更精确 | 需要知道物体的"可抓面"，要建模 |

**建议先用"掌心 → 物体中心"**（简单通用），后续再细化。

### 点 3：手出画 / 标记遮挡
- 手背标记在抓握瞬间可能被手指或物体挡住 → 那些帧的标签要丢弃（用可见性/置信度过滤）
- 用 MediaPipe 检测手是否完整可见 → 自动筛

## 六、⭐ 极简流程（自由动作 + 零标注）

```
【采集】
  手背 + 物体 各贴一个 ArUco 标记
  受试者**自由**抓取 5 种物体（放在桌面不同位置）
  单目相机录像（固定支架或头戴）
        ↓
【自动造标签】
  逐帧检测两个标记 → R_hand, p_obj
  → 代入几何公式 → 「需要转多少 / 旋前还是旋后」
  → 同时用 MediaPipe 筛掉手不可见的帧
        ↓
【训练】
  单帧 RGB → 预测 { 抓握类型(5类), 腕旋修正(3类 或 连续角) }
        ↓
【部署】
  去掉标记，模型只看图像 → 输出抓握 + 腕旋指令
```

**工作量的本质**：**打印两张标记纸 + 自由抓几百次 + 跑一个自动脚本**。
**没有 IMU、没有仿真、没有 RL、没有人工标注。**
