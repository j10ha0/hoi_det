# 自己采集时如何标定？—— 完整协议

> 你的观察：**EgoDex 数据全是动态的，完全没有"校准/检测场景"**
> **为什么这是问题**：动态数据**无法验证**（不知道姿态估计准不准）、**无锚点**（不知道起点终点）、
> **无法检测漂移**（长时采集后标记/编码器是否偏移）。
> **ML 数据集的可信度，恰恰来自静态参考片段。**

---

## 一、⭐ 先明确：你要"标定"的是四样东西

| # | 标定项 | 用途 | 频率 |
|---|-------|------|------|
| 1 | **相机内参**（K + 畸变）| 3D→2D 投影、算方向、可视化验证 | **一次性**（换相机/变焦才重标）|
| 2 | **相机外参**（相机 ↔ 桌面/世界）| 绝对坐标；物体位置换算 | 固定支架：一次<br>**头戴：每次佩戴都要** |
| 3 | **手姿来源标定** | 标记/传感器的局部系 → **掌心法向** | 一次性 |
| 4 | **物体位置** | 标签计算（手-物相对关系）| 每次摆放（或用标记自动）|

---

## 二、⭐ 最关键：加「静态参考片段」（EgoDex 缺的就是这个）

**在动态采集之外，额外录一组"已知状态"的静止片段**，每段 3–5 秒：

### 2.1 掌心朝向参考（4 段）
```
手摊开，掌心朝下 → 静止 3–5 秒
手摊开，掌心朝上 → 静止 3–5 秒
手摊开，掌心朝左 → 静止 3–5 秒
手摊开，掌心朝右 → 静止 3–5 秒
```
**作用**：
- ✅ **验证姿态估计精度**（真值已知：掌心就该朝那个方向）
- ✅ **提供类别视觉先验**（"掌心朝下"长什么样）
- ✅ **作为可控测试集**（可复查、可对比）

### 2.2 手位置参考（3–5 个已知位置）
把桌面贴格子/标记，手依次放到每个位置静止。

### 2.3 物体参考（每个物体在每个位置静止）
物体放在标记/格子上静止 2–3 秒 → 物体位姿的锚点。

### 2.4 ⭐ 逐 trial 锚点（最重要，成本极低）
```
每次抓取：
   ① 伸手前：手静止 1 秒      ← "起始态"锚点
   ② 抓稳后：保持 1 秒        ← "终态"锚点（也是"对准完成"的参考）
```
**这 2 秒静止能给你**：
- 起始腕旋角 / 终止腕旋角（用于自监督代理标签的锚点）
- 检测漂移（相邻 trial 之间的静止帧应该一致）

## 三、⭐ 完整采集流程（可执行 checklist）

### Stage 0 · 相机与坐标系标定（约 10 分钟，一次性）
```
[ ] 打印 ChArUco 板（推荐）或棋盘格，贴在硬板上（保证平整）
[ ] 相机固定好后，手持标定板在视野内不同姿态拍 20–30 张
    → cv2.calibrateCamera() → 内参 K、畸变系数
[ ] 标定板平放桌面（已知位置）→ cv2.solvePnP() → 相机↔桌面外参
[ ] （头戴相机）每次佩戴后，拍一次桌面标定板 → 当次外参
[ ] 保存 calibration.json（K、畸变、外参、时间戳）
```

### Stage 1 · 静态参考片段（约 5 分钟）
```
[ ] 掌心朝下/上/左/右  各 3–5 秒
[ ] 手放 3–5 个已知位置  各 3 秒
[ ] 每个物体在每个位置静止 2–3 秒
[ ] 保存为 calib_*.mp4（单独目录，不混进训练数据）
```

### Stage 2 · 动态采集（约 20–30 分钟）
```
[ ] 物体放在带标记/格子的桌面（位置已知）
[ ] 每次抓取：【伸手前静止 1 秒】→ 自由伸手 → 对准 → 抓握 → 【抓稳后静止 1 秒】
[ ] 每 10 个 trial 做一次"参考动作"（防止漂移）
[ ] 记录：物体 ID、位置编号、时间戳
```

### Stage 3 · 校验（每次采集结束）
```
[ ] 重录一次 Stage 1 的静态片段
[ ] 与开头对比 → 若姿态估计偏差 > 阈值 → 本次数据不合格/需重标
```

## 四、⭐ 一个能大幅简化标定的技巧：**用"相对量"当标签**

**如果你只关心"手-物相对关系"**（我们的对准误差正是如此）：
```
ê = f( 手姿态, 物体位置 )     ← 都是"相对量"，不是绝对坐标
```
**→ 只要相机同时能看到手和物体 → 绝对外参【不需要】！** ⭐

**这解决了头戴相机最大的麻烦**：
| | 需要绝对外参? | 说明 |
|--|-------------|------|
| 用绝对坐标算误差 | ✅ 需要 | 头戴相机每次佩戴都要重标 |
| **用相对关系算误差** | ❌ **不需要** | 相机只要同时看到手和物 → 直接算相对量 |

**→ 头戴相机方案因此大幅简化**（只需内参，不需要每次标外参）。

## 五、最简可行版本（如果只想先跑通）

```
必须:
  [ ] 相机内参（一次性，20 张标定板）        ← 用于可视化验证
  [ ] Stage 1 静态参考片段（5 分钟）         ← 验证 + 锚点 ← 最重要
  [ ] 物体放在标记/格子上（位置已知）         ← 标签计算
  [ ] 每 trial 前后各静止 1 秒               ← 锚点

可以省:
  [ ] 相机外参（用相对量标签就不需要）
  [ ] 手姿来源标定（如果用编码器/标记，标定很简单）
```

## 六、工具与代码

| 任务 | 工具 |
|------|------|
| 内参标定 | `cv2.calibrateCamera` / ChArUco（`cv2.aruco.CharucoBoard`）|
| 外参 / 位姿 | `cv2.solvePnP` / `cv2.aruco.estimatePoseSingleMarkers` |
| 标记生成打印 | `cv2.aruco.generateImageMarker` / [AprilTag 生成器](https://chaitanyantr.github.io/apriltag.html) |
| 更严格标定 | Kalibr（相机-IMU）、MATLAB Camera Calibrator |
| 数据组织 | 建议每个 session 一个目录，含 `calibration.json` + `calib_*.mp4` + `trials/` |

```python
# 内参标定骨架
crit = (cv2.TERM_CRITERIA_EPS + cv2.TERM_CRITERIA_MAX_ITER, 30, 0.001)
objp = np.zeros((6*9, 3), np.float32); objp[:, :2] = np.mgrid[0:9, 0:6].T.reshape(-1, 2)
objpoints, imgpoints = [], []
for f in glob("calib_board_*.jpg"):
    gray = cv2.cvtColor(cv2.imread(f), cv2.COLOR_BGR2GRAY)
    ok, corners = cv2.findChessboardCorners(gray, (9, 6), None)
    if ok:
        objpoints.append(objp)
        imgpoints.append(cv2.cornerSubPix(gray, corners, (11,11), (-1,-1), crit))
ret, K, dist, _, _ = cv2.calibrateCamera(objpoints, imgpoints, gray.shape[::-1], None, None)
```

## 七、⭐ 回答你的问题

> **"EgoDex 数据不好，全是动态的，没有校准检测场景。我自己采集该怎么标定？"**

**四件事**：
1. **相机内参**（一次性，标定板 20 张）→ 用于投影与可视化验证
2. **静态参考片段**（⭐ 最重要）→ 掌心 4 个朝向 + 手/物若干已知位置，各静止 3–5 秒
   → **这是 EgoDex 缺的，也是你数据"可验证"的来源**
3. **逐 trial 锚点**（伸手前 1 秒 + 抓稳后 1 秒静止）→ 提供起始/终止腕旋角，还能检测漂移
4. **物体位置已知**（标记/格子）→ 标签计算

**还可以省掉一半**：
> 因为你的标签是「手-物**相对**关系」→ **头戴相机不需要每次标外参**，只需内参 + 能看到手和物。

## 八、需要你确认

1. **相机是头戴还是固定支架？**（决定要不要每次标外参 —— 用相对量标签的话头戴也行）
2. **物体位置能否固定摆放**（格子/标记）？
3. **能接受"每 trial 前后各静止 1 秒"吗？**（成本极低，收益很大）
4. 标定板你有吗？（没有的话我可以说怎么快速做一张）
